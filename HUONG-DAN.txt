HƯỚNG DẪN SỬ DỤNG TRANG TRUYỆN
================================

BỘ FILE NÀY GỒM:
- index.html      -> trang chủ, tự động liệt kê danh sách truyện
- story.html       -> trang đọc truyện (dùng chung cho MỌI truyện)
- stories.js       -> nơi DUY NHẤT bạn cần sửa để thêm/sửa/xóa truyện
- style.css        -> giao diện, không cần đụng vào
- audio/           -> nơi để các file mp3 (nếu bạn muốn upload mp3 lên thẳng đây)


1. CÁCH THÊM MỘT TRUYỆN MỚI
----------------------------
Mở file stories.js, bạn sẽ thấy mảng STORIES chứa các khối như thế này:

  {
    slug: "ten-khong-dau-khong-cach",
    title: "Tên truyện hiển thị",
    date: "07/09/2026",
    tags: ["Tình cảm", "Đô thị"],
    excerpt: "Một câu mô tả ngắn hiện ở trang chủ.",
    paragraphs: [
      "Đoạn văn thứ nhất.",
      "Đoạn văn thứ hai.",
      "Đoạn văn thứ ba."
    ],
    audio: "audio/ten-file.mp3",
    youtube: "IDvideoYoutube"
  },

Copy nguyên khối này (từ dấu { đến dấu }, ), dán vào NGAY TRƯỚC dấu ]
đóng mảng ở cuối file, rồi đổi các giá trị:

- slug     : đặt tên viết liền không dấu, không khoảng trắng, không trùng
             với slug của truyện khác (dùng làm đường link, vd: "truyen-so-3")
- title    : tên truyện, muốn viết gì cũng được, có dấu bình thường
- date     : ngày đăng, chỉ để hiển thị
- tags     : danh sách thể loại của truyện, viết trong ngoặc vuông [ ],
             mỗi thể loại để trong ngoặc kép, cách nhau bằng dấu phẩy.
             Ví dụ: tags: ["Tình cảm", "Học đường"]
             Nếu chưa muốn gắn thể loại thì để: tags: []
             Trang chủ sẽ TỰ ĐỘNG hiện thanh lọc theo tất cả các thể loại
             đang có trong stories.js, không cần khai báo danh sách thể loại
             ở đâu khác — chỉ cần gõ tên thể loại trong tags là đủ.
             Gõ giống hệt chính tả ở các truyện khác (vd luôn viết "Tình cảm",
             đừng lúc thì "Tinh Cam" lúc thì "tình cảm") để không bị tách
             thành 2 thể loại khác nhau.
- excerpt  : câu mô tả ngắn hiện ở trang chủ
- paragraphs: mỗi dòng trong ngoặc kép " " là MỘT đoạn văn.
             Muốn thêm đoạn thì thêm dòng mới, nhớ có dấu phẩy giữa các dòng
             (dòng cuối cùng không cần dấu phẩy)
- audio    : nếu có mp3 thì ghi "audio/ten-file-mp3-cua-ban.mp3"
             nếu chưa có thì để trống: ""
- youtube  : chỉ cần ID của video, KHÔNG phải link đầy đủ.
             Ví dụ link là https://www.youtube.com/watch?v=dQw4w9WgXcQ
             thì ID là phần sau "v=" -> dQw4w9WgXcQ
             Nếu chưa có video thì để trống: ""

LƯU Ý: mỗi khối phải cách nhau bằng dấu phẩy ",", và toàn bộ chữ/dấu ngoặc
kép phải giữ nguyên định dạng như mẫu — chỉ đổi NỘI DUNG bên trong ngoặc kép.

Truyện thêm sau cùng trong file sẽ tự động hiện ở TRÊN CÙNG trang chủ.


2. CÁCH XÓA MỘT TRUYỆN
------------------------
Mở stories.js, tìm khối { ... } của truyện muốn xóa (nhận ra qua "title"),
xóa nguyên khối đó từ dấu { đến dấu } cùng dấu phẩy theo sau. Nhớ không để
sót dấu phẩy thừa (2 dấu phẩy liền nhau hoặc thiếu dấu phẩy giữa 2 khối
còn lại sẽ làm trang web bị lỗi trắng trang). Xóa xong bấm Commit changes
là trang chủ tự cập nhật ngay.


3. CÁCH THÊM FILE MP3
----------------------
Cách dễ nhất: bỏ file mp3 vào thư mục "audio/" ngay trong bộ file này,
rồi ghi tên file vào ô "audio" trong stories.js như trên.
Khi upload lên GitHub, chỉ cần kéo cả thư mục audio lên cùng.


4. CÁCH ĐƯA TRANG WEB LÊN MẠNG (GitHub Pages, miễn phí)
---------------------------------------------------------
Xem hướng dẫn từng bước ở phần chat — mình đã tách riêng thành các bước
dễ làm theo, không cần dùng dòng lệnh, chỉ cần kéo-thả file trên trình duyệt.
